# コツンズ Attack / Defence / Recover 最新必殺技仕様（v4 新450キャラ）

この文書と `data/special_config_new450.json` が、以前のv3仕様と衝突する場合は **今回の最新版として優先**。必殺技は *すでにゲームに実装されたものではない*。ゲーム既存機能は壊さず追加する。

## 目的と役割の差

|種類|発動条件|小25pt|中55pt|大90pt|特徴|
|---|---|---:|---:|---:|---|
|Attack|**1位正解した時だけ**|追加+3|追加+5|追加+8|早押しが最も得意な人向け。1位以外はゲージ消費なし|
|Defence|**正誤・順位に関係なく有効宣言時**|4軽減|8軽減|12軽減|誤答・時間切れ・早押し負けの被害も防御できる。宣言時のゲージを必ず消費|
|Recover|**正解すれば何位でも**|回復6|回復11|回復16|1位正解なら追加3/5/7、低HP時追加2/3/4、回復あふれを小さな次問シールドに変換|

数値はすべて HP 絶対値（%ではない）、初期値であり、**テスト前の仮設定**。レア度／進化／レベルの微量な段階補正と各技の絶対上限は `special_config_new450.json` にまとめる。大人数戦、少人数戦、ミス頻度に対するバランス検証が必要。

### ゲージ
- 全キャラ共通1本、0〜100、スタート10。小25／中55／大90。得意・苦手・連続正解・属性相性による増減は旧v3の参照数値を維持。
- 問題ジャンル公開後〜回答表示前に、*所持している*技1件とティアを選択。問題表示前400msまでを受理目安とするが、実装時は既存ホストのタイムラインに合わせる。通信ACK前に確定表示をしてはいけない。
- 技に必要なゲージがあるかは **問題開始時点の残高** で判定し、今問正解ボーナスによる後払いを禁止。
- Attack：正解1位→発動・消費。不正解／1位以外→不発・コスト0。
- Defence：宣言が受理された時点でこの1問に有効。**正誤・順位にかかわらず消費し、被ダメージ0でも消費**。対価として確実な安心が得られる。KOしている人、期限切れ、ゲージ不足、同時に選べない技は不受理／コスト0。
- Recover：正解→発動・消費。正解1位→追加回復。不正解→不発・コスト0。
- 上記とは別に、従来の不正解による自然減少（-2/-4/-3）は通常どおり。特にDefence不正解時は「防御コスト＋通常不正解減少」になるため事前UIに明示する。

### ダメージ順序・KO
1. ホストは正答・回答順・通常ダメージ・スキル宣言・各人の問題開始残高を確定。
2. Attackの1位条件と防御受理を検証し、追加攻撃量を決める。通常攻撃が届く相手にだけ追加し、上限を守る。
3. Defenceは **全参加者の結果がどうであろうと** 被ダメージから軽減。複数ダメージは総和後に同問1回だけ軽減。反射のダメージは二次反射を起こさない。
4. Recoverは不正解以外の生存者に適用。**同一問題の被ダメージと回復を合算した最終HPが1以上なら生存**してよい（救命回復）。前の問題でKO済みの人は復活不可。
5. HP確定後に結果を公開し、正しいスキル費用とゲージ獲得／減少を一度だけ適用。UIが演出に失敗しても、計算結果は不変。
6. 反射や追加ダメージでKOしても、早押し回答順や順位は変えない。

### 回復役が弱くならないための仕組み
- 1位になれない人でも「正解した」という知識が戦術になる。
- 強めの基本回復量、1位ボーナス、残りHP35%以下の緊急追加回復、あふれた回復の **最大1/2/3の次問シールド** で腐りにくくする。
- シールドは1問で失効、重複して積み上がらない。正解だけで無限のHPが増えるわけではない。回復のHP上限は必ず守る。
- 同じ問題で残HP2・被ダメ8・回復11なら HP5で生き残れる（それ以前にKO済みの復活ではない）。

### ミラー防御
- 一部の個別防御技にだけ付くサブタイプ。宣言すれば通常のDefenceと同じく**誤答でも軽減**。
- 実際に軽減したHPを最大6まで記録（有効期限は次の2問）。次に**このミラー防御を選んで、その問題で1位正解した**時だけ、記録値＋今問の実軽減値の最大50%から小さく反射。小1/中2/大3を上限に、対象の生存者へ整数で公平に分配。
- **同じ問題で1位を取った人に本来の被ダメージが0なら、0は反射できない。** 過去にその本人がブロックした実被ダメージが残っている時のみ反射できる。何もブロックしていないのに反射ダメージが発生しない。
- 一方通行の追加ダメージとして処理。反射の反射、ダメージの無限増殖は禁止。対象の自動選定はホストが検証済みの生存者のみで決める。

### 2種類の固有技
- 全員共通の小攻撃／小防御などに加え、個別デザインを持つ「固有必殺技」を各キャラ2件記録。
- おつ／普通／レア：S1では固有技1件、S2から2件。スーパーレア／レジェンド：S1から固有技2件。
- S3になっても同時発動は不可。ゲージ1本・1問1技・コスト共通。
- 2件目の技は別の役割。たとえば「Attack＋Defence」「Attack＋Recover」「Defence＋Recover」。どちらも選べるのであって、重ね掛けではない。
- 個別技のレベル補正は同じ絶対数値の小さな加点。最高レベルやレジェンドが初心者を絶対に倒す状態にしない。早押し実力が第一。

### 無条件に守ること
- 他人の技選択・ゲージ・効果は問題が終わる前に漏らさない。
- 封印・ヒントなど旧v3の複雑な特殊効果は今回の主3系統には**勝手に混ぜない**。既存で実装されているならリグレッションをとって互換性を相談する。
- 不正確な端末時刻で順位を変更しない。ホスト権威、重複イベント防止、遅延や再接続の整合性が必須。
- 課金・リアルマネーガチャは許諾／法務／サーバー保護まで導入しない。
