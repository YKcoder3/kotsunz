# 権利・類似性・商標・画像品質の実査と一般公開の実行手順（v3）

## ゴール：確認のための無期限停止ではなく、**確認を完了して一般公開する**
開発者は新450キャラの公開を明示的に希望し、必要なチェックを完了した場合の一般公開も依頼済み。Claudeは「権利・商標が心配」と報告して終わらず、調査/記録/修正/テスト/公開まで進める。**ただし未確認事実を「確認済み」と偽ることは不可**。

## 現在の客観的な確認範囲
- 元ZIPには21枚の画像シートが収録されているが、**制作元、商用利用許諾、参照画像、権利帰属に関する証憑は含まれていない**。画像の見た目やファイル名だけで商用利用許諾は判断できない。
- 450系列の3連画像と各形態1350WebPは切り出しデータ。ファイルの存在/ハッシュ検証と**全450の画像品質・著作権・商標調査の完了は別**。
- 今の `publishable:false`, `copyrightStatus:'unverified_rights_review_required'`, `artReviewStatus:'needs_visual_crop_QA'` は **未確認を示す初期値**。永続的な公開禁止ではない。根拠がそろった段階で必ず更新し、正式版で公開する。

## 1. 制作元・商用利用権（21枚）
`data/source_rights_21.csv` を各シート分埋める：制作者、制作/生成手段、制作日、使用サービスと規約、参照画像の有無、権利・改変/商用/ウェブ公開の許可、第三者素材混入の確認、根拠URL/許諾書など、確認者・日付。
- 人や会社が制作したものならライセンス・契約・権利譲渡や使用許諾範囲を確認。
- AI生成なら生成に用いたサービスと当時の規約、参照画像の使用権利、類似性・依拠性リスクを確認。
- ZIPから調べられないところは開発者に証憑を要請し、受け取った証拠を記録する。**存在しない権限を仮定しない**。

## 2. 450系列の類似作品・ロゴ・商標調査
`data/release_review_450.csv` を埋める。全450系列に対し：見た目の既存キャラ/企業マスコット/ロゴとの類似性、参照元の疑いの確認、名称・称呼の商標、ストーリー・必殺技の名称、画像3形態の切り出し・輪郭・他キャラ混入・スマホ表示の品質を記録。具体的な比較先やURLと検索日を残す。問題を見つけたら当該名称/画像を修正し、再確認。
参考：文化庁（AIと著作権） https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html 、J-PlatPat（商標） https://www.j-platpat.inpit.go.jp/t0100
検索・目視チェックだけで法的な非侵害を完全保証できるわけではない。懸念が解消しない案件は許諾取得、差し替え、専門家確認が必要。

## 3. 画像・コード・対戦ゲームの検証
450系列の元の三連画と `NZxxx-S1/S2/S3` の一致、画質、切り出し欠け/混入/透過・余白・スマホでの収まりを `qa/character_gallery.html` 等で確認。画像名から類推して未確認で合格扱いしない。
クイズ/早押し/CPU/オンライン/ガチャ/育成/進化/必殺技の回帰テスト、旧キャラ全廃と旧セーブ初回のみリセットテストを実施。問題は修正→再テスト。

## 4. 公開までの明確な作業
1. 調査・権利証憑・画面QAを記録し、`data/source_rights_21.csv` の21行、`data/release_review_450.csv` の450行を**すべて根拠付きで合格**にする。
2. `python scripts/approve_release.py --check` で未完了が0件になることを確認する（証拠がない状態で強制許可しない）。
3. `python scripts/approve_release.py --approve --reviewer "確認責任者"` で `data/characters_450.json` の `publishable:true`、`copyrightStatus:'rights_review_completed'`、`artReviewStatus:'approved'` を反映。アーカイブのための記録を残す。**このスクリプトは合格記録の存在を検査するが、法的な真実性を自動的に証明しない**。
4. GitHub Pagesの静的ホスティングを前提に、現行リポジトリを確認してデプロイ。公開URLで全アセット・ゲーム機能・セーブ初期化の動作を確認する。権限・承認フローが足りなければPR/適用コマンド等を用意して実際の未公開状態を報告。
5. 完了報告に「公開URL、コミット、デプロイ時刻、確認した根拠、権利上の残存注意、テスト結果、公開時の注意」を書く。

## 公開判断
- **すべてが確認・対処済み:** 新450キャラの一般公開へ進める（別の公開可否の再質問は不要）。
- **制作元・商用利用権の根拠が欠ける:** 根拠を開発者へ請求し、偽の公開承認をしない。資料受領後、確認と公開を再開する。
- **1体でも著作権・類似性・商標・切り出し品質に未解決の懸念:** 必要ならそのキャラを修正し、解決後公開。無断利用の疑いがある画像をチェックせずに上げない。
