# Claudeにそのまま渡す実装指示

あなたはWebゲーム「KOTSUNZ（コツンズ）」の既存コードを安全に改修するエンジニア兼ゲームデザイナーです。添付されたKOTSUNZ完全実装パックV4を展開し、まず `00_START_HERE_CLAUDE.md` と `docs/01_DATA_MODEL.md`・`docs/02_BATTLE_AND_UI.md`・`docs/04_SPECIAL_BATTLE_SPEC.md` をすべて読んでください。最新の GitHub リポジトリ `YKcoder3/kotsunz` を確認し、機能差分と旧セーブ方式を調べてください。

## 必須の成果
1. 既存50体のIDとセーブデータを壊さず、**500基本キャラ/1500進化形態**へ拡張。ガチャ・図鑑・所持一覧・お気に入り・コツン誕生・3体重複進化・覚醒・育成・HP対戦を維持。
2. 全500体に固有必殺技を追加。全員に共通攻撃/共通防御も追加。`data/special_skills_500.json` と `data/special_config_v3.json` の数値と名称を**実際の表示と判定**に使用。
3. **ジャンル表示後・問題の本文表示前**に `攻撃 / 守り / 固有技` と `小25 / 中55 / 大90` を選択できる。正解なら発動・消費、不正解なら不発・コスト不消費。発動者と技名は結果画面で全員に通知（問題出題前に他人へ公開しない）。
4. 初期ゲージ10、上限100。正解・1位・連続正解・連続1位・得意/苦手ジャンル克服で、詳細仕様通りに増減。難易度を保ちつつ対戦中に数回使えるテンポにする。
5. 6属性維持。得意ジャンルは淡い金色のキラキラ、苦手は読みやすい暗め紫。属性有利・得意/苦手は主に**ゲージ増減**へ作用させる。旧 `得意で攻撃1.5倍`、`苦手で防御1.4倍` など重なるダメージ倍率は新モードでは廃止。苦手で不正解した場合だけ、ダメージを**最大2HP固定軽減**する例外は設ける（割合ではない）。
6. キャラ詳細画面から**「強さ」「ワンポイント」欄は削除**。レア度・属性・得意/苦手・進化・必殺技名/効果・物語は表示する。
7. 500体×3の**SVG仮画像1500点**を表示用フォールバックとして接続。正式な高品質画像は現在未制作であることを維持し、存在する画像を優先して表示し、存在しないWebPにはアクセスしない。 `art/premium_reference` は画風参考であり、1枚から切り出したサンプルを勝手に本採用しない。
8. コラボ枠を本編と分離。Disney、アニメ、ドラマの実在キャラ・衣装・ロゴなど**ライセンス未取得の素材は公開、抽選、配布しない**。ライセンス許諾後に解放できるデータ構造と管理UIのみ用意。
9. 既存のCPU対戦・オンライン最大10人・MQTT通信・回答順位判定・セーブと移行を保持。ホスト権威でゲージ・技判定を行い、クライアントのダメージ値やゲージ残量を信用しない。

## 改修順序
A. 最新コード取得、セーブデータのバックアップ、ブランチ作成。
B. データマイグレーションと500体マスター検証。SVGプロトタイプを読み込む。
C. 必殺技エンジンを純粋関数で統合。ゲージ・正誤・HP上下限・連続ボーナス・状態異常の単体テスト。
D. CPU対戦 → ローカル対戦 → オンライン対戦の順に、ホスト同期 `skillIntent / skillAck / res.skillEvents` を実装。
E. スマホ画面のUI・エフェクト・結果画面・図鑑詳細を変更。発動演出は0.5〜1.2秒程度で、回答を邪魔しない。
F. 全テストと回帰確認。完成した実装箇所・テスト結果・未対応箇所を報告し、ユーザー承認前に本番mainへ強制上書きしない。

**禁止**：仮SVGを『最高品質の完成イラスト』と呼ぶこと、500体のイラストを生成済みと偽ること、有料ガチャを先行実装すること、無許諾の既存作品コラボを公開すること、既存セーブを初期化すること。
