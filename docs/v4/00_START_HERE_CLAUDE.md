# KOTSUNZ — Claude 完全実装パック V4（500体・1500形態・500固有必殺技）

このZIPは「キャラ名を並べた資料」ではなく、**キャラマスター / 全進化形態 / ゲーム数値 / 500固有必殺技 / 画像指示 / 仮画像 / 高品質参考画像 / 参考コード / 検証手順**を統合した実装用一式です。

## 最初に知っておくこと
- オリジナルキャラ：**500系統（K001〜K500）**、進化：各3段階、図鑑形態：**1500**。
- 固有必殺技：**500件**（全員が別々の名前と演出指示を持つ）。共通技は攻撃・防御。
- レア度：おつ45%、普通35%、レア15%、スーパーレア4.5%、レジェンド0.5%。**これはレア度の抽選確率であり、そのレア度の各キャラがその確率で出るわけではありません。**
- 属性：論理派・直感派・記憶派・スピード派・逆転派・ひらめき派。相性は原則ゲージの獲得に作用。攻撃力の割合倍率ではない。
- 必殺技：小25pt／中55pt／大90pt。**ジャンル公開後・設問表示前に宣言し、その設問に正解したときだけ発動・消費**。誤答ではコストは消費せず、通常のゲージ減少のみ。
- 500種のSVG仮画像×3段階＝**1500枚、コードで描いたプロトタイプ**。各キャラを識別できるが、完成イラストの代わりにはならない。
- **高品質イラスト：12体をまとめたコンセプトシートと12個の切り出し見本**のみ。500体×3段階の高品質完成画像は**未制作**。商品化／本番グッズ用としては承認しない。
- Disney・アニメ・ドラマの実在IPはライセンス未取得。コラボ枠は**ロックされたデータ**だけ。本編・ガチャ・公開画像には入れない。
- ユーザーの現行アプリは `YKcoder3/kotsunz`。コードの最新版を改めて取得してから改修。**このZIPはGitHubに未反映**。

## 実装に使うデータ
- `data/characters_500_full.json`：**500キャラの詳細説明・性格・画像条件・発言・進化設定**。主要マスター。
- `data/special_skills_500.json`：**500固有必殺技の名前・効果系統・演出・キャラ対応**。
- `data/forms_1500.json`：全進化形態の定義、プロトタイプ画像パス、正式アセット未制作状態。
- `data/game_config_500.json`：ガチャ/育成/進化/属性の統一設定。
- `data/special_config_v3.json`：必殺技の数値、例外、上限の**唯一の正**。
- `data/genres.json`：現在のクイズジャンルのキー表。
- `data/collaboration_registry.json`：未許諾IPの非公開枠。
- `data/art_prompts_1500.json`：形態別の1,500件の完成イラスト生成指示。
- `art/svg_prototypes/k001/stage-1.svg`等：**仮画像**（各ステージあり）。
- `art/premium_reference/premium_12_character_concept_sheet.png`：完成画風の**参考**（複数キャラ。公式最終素材ではない）。
- `art/production_prompts/prompts_1500.jsonl`：大量画像制作のための逐次処理データ。
- `code/special_engine.mjs`：純粋関数の参考コード、アプリ全体への統合は未完了。

## 重要な注意
**ZIPを読み込ませるだけで500体の高品質画像が自動生成されたとは言わないこと。** まずSVGで図鑑とゲームを成立させ、キャラごとの一貫した見た目を承認してから生成画像に差し替える。ClaudeにはZIP添付と `01_COPY_TO_CLAUDE.md` の指示文を一緒に渡す。
