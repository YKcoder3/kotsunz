# 7. QA・実装確認リスト

## マスターデータ
- [ ] K001〜K500が重複なく500件。各キャラに固有必殺技1件（計500）。
- [ ] K001〜K050の既存IDとキャラ名が変わっていない。
- [ ] ステージS1/S2/S3の形態が全1500件、重複なし。
- [ ] 全キャラが6属性のどれか、レア度5種類のどれか。
- [ ] 得意/苦手ジャンルが登録済みのIDのみ、重複しない。
- [ ] キャラ固有技の効果系統が設定ファイルの8系統のみ。
- [ ] 特技、攻撃、防御、回復は本編に表示される。旧「強さ」「ワンポイント」欄は削除。

## 必殺技
- [ ] 始点10/100、小25・中55・大90。
- [ ] 宣言した問題で正解したときだけ消費・発動。誤答・時間切れは技コスト不消費。
- [ ] 参加者同士、相手の技宣言は問題結果まで見えない。
- [ ] 連続正解・連続1位・得意・苦手克服のゲージ増減を検証。
- [ ] 1問+34上限、負数や100超えなし。
- [ ] 同ラウンドの再送で技コスト二重消費なし。
- [ ] 3択は自分の誤答だけ1個消える。封印は次問1回の技宣言だけ。
- [ ] 必殺技が誰かを一度に全滅させるような数値でない。
- [ ] KOした後の回復や再生でゲームを壊さない。

## クイズ・通信
- [ ] 4択が通常機能、早押し順位・HP処理・試合結果が正常。
- [ ] CPU対戦と2台のオンライン対戦、途中再接続。
- [ ] スマホ縦画面で技選択でき、問題本文/選択肢が見切れない。
- [ ] 得意の控えめキラキラ、苦手の暗い紫、アニメ削減設定。
- [ ] 既存ユーザーのキャラ・レベル・コイン・所持数・図鑑が保持。

## 画像・知財
- [ ] SVG仮画像1500枚を読み込める。画像の読み込みエラーはフォールバック。
- [ ] 高品質の参考画像12体を本番素材として勝手に採用しない。
- [ ] 未許諾のDisney・アニメ・ドラマ固有の衣装・キャラ・ロゴがゲームに表示されない。
- [ ] 本番商用化前に絵・名前・商標の類似チェックと第三者素材の許諾確認。
- [ ] 本番有料ガチャはまだ無効。導入する場合はサーバー権威化、明確な確率・年齢配慮・規約など追加検証。
