# コラボ / ガチャ / 権利 / 収益運用メモ

## コラボ専用枠
- オリジナル500キャラ（K001〜K500）のほか、独立の `collab` カタログを作る。ライセンス作品の「衣装スキン」も「単独ゲストキャラ」も識別可能にする。
- コラボにも同じ五段階を用いる：おつ45%、普通35%、レア15%、スーパーレア4.5%、レジェンド0.5%。**これはコラボ専用バナーを実施すると仮定したときの案**であり、作品との契約・監修・法務確認の前に公開してはならない。
- レア率の合計は100%。バナー内の実際の排出対象数と各キャラの個別排出率を表示。全500種を一度に排出させる必要はない。テーマ別の常設/期間限定バナーを設計する。
- 作品コラボのキャラ・衣装・音声・ロゴ・名称・セリフ等は権利者の許諾が必要。**Disney、アニメ、ドラマの名称を企画候補として内部に書くだけならよいが、無許諾の再現絵や宣伝・公開はしない。** ドラマは俳優の肖像やパブリシティ関連にも注意。
- `data/collaboration_registry.json` の契約未了枠はすべて `approved:false`,`publishable:false`,`gachaEnabled:false`。公開UIには出さない。デモ用には「ほしぞらたんけん」「こそこそ探偵団」「おとぎの迷宮」など完全に独自の衣装テーマを使う（既存作品の意匠に寄せない）。
- 契約締結後の管理項目：`ipOwner`, `territory`, `platform`, `releaseWindow`, `contentApproval`, `artApproval`, `merchRights`, `musicRights`, `marketingApproval`, `creditText`, `expiryAndTakedownPlan`。

## 3体重複進化と法律
- S1の同一キャラクターを3体揃えてS2に進化させる。**異なるキャラA+B+Cを集めて景品Dを与えるコンプガチャとは分ける。** 消費者庁FAQでは同一種類のカードを複数集める方法は、通常のカード合わせに該当しないと説明する。ただし具体的条件に応じて個別判断が必要。
- 消費者庁「インターネット上の取引と『カード合わせ』に関するQ&A」：https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/card/
- 将来、有料ガチャにする場合は景品表示、確率、購入制限、未成年の保護、返金、特商法表記、ストア規約などを専門家と精査。

## 経済バランス
- まず無料コインでテスト。単発100、10連1000は仮案。レジェンド0.5%を15種から均等に出すなら常設全種プールでは**特定レジェンド1種の確率0.0333%**。その特定1体を3枚狙うのは平均9,000回抽選相当なので、初心者向け設計として不適切になり得る。
- 対策：特定キャラのピックアップ、選択交換券、無料進化素材、ミッション救済、天井など。ただし確率と仕様を実装・検証し、事前に明示する。
- レジェンドでも対人クイズの知識や回答速度を上回る性能補正をしない。価値は演出、表情、スキン、図鑑、ストーリーに置く。

## 技術的な制約
- 現行はブラウザローカル保存と公開MQTT試作。**有料化前にサーバー権威型のガチャ抽選、所有キャラ、残高、重複進化のトランザクション、レシート検証・改ざん防止が必要。** 無料版プロトタイプではローカルでもよい。
- 既存データ移行ではK001〜K050の stable ID を保持し、旧セーブを先にバックアップし、重複移行を防ぐ。
