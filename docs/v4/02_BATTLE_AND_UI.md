# 2. クイズ対戦と必殺技 — 詳細UI仕様

## 原則
キャラを持っていれば、誰でもクイズの知識と反射神経で勝負できる。技はプレイヤーが賢く使う補助。数字を「攻撃力×1.8」のように積み重ねず、実際の追加HPダメージ・軽減・回復を簡潔に見せる。

## ゲージ
- 初期10、上限100。小25／中55／大90。利用可能な階層が点灯。
- 正解+14、正解1位+8、2連続正解+3、3連続以上+6、2連続1位+4、3連続以上+7。
- 得意で正解+4、得意1位でさらに+5、苦手で正解+8、苦手1位さらに+3。属性有利で正解なら+2（1問1回まで）。正解獲得上限+34。
- 誤答は通常-2、得意-4、苦手-3。自然に下がるだけ。宣言失敗による特別なペナルティはない。
- **大技を選択して不正解**：大技分を消費せず、前述の小さな減少だけ。発動していないのにゲージが0にならない。
- 同問で使う技のコストは**ジャンル公開時点で持っていたポイントから消費**し、正解獲得分は後で加算。

## 共通技と固有技
| 技 | 小25 | 中55 | 大90 |
|:--|--:|--:|--:|
| 共通攻撃 | 通常攻撃対象に+3HP | +5 | +8 |
| 共通守り | 自分の受けるHPを4軽減 | 8 | 12 |

固有技： `burst` 追加攻撃、`shield` 防御、`heal` 回復、`hint` 次問自分のみ3択、`seal` 次問対象1人の技宣言のみ封印、`cleanse` 状態解除、`focus` 回復＋次問正解時ゲージ補助、`comeback` 弱い攻撃と回復の同時発動。詳細HP数値と上限は `special_config_v3.json` のみから決定。

レア・進化強化は固有技の**HP数値1項目だけ小さく上乗せ**、上限あり。対象人数・封印継続時間・選択肢除外数は増えない。レジェンドでも一撃で全員KOできない。

## 一問の画面
1. ジャンル発表：上部にジャンル、HP、ゲージ（数字/100＋25/55/90目盛）。得意なら淡い金色粒子、苦手なら落ち着いた紫の暗い背景。どちらもラベルと文字を併記し、色のみで情報を伝えない。
2. `攻撃 / 守り / 固有技名` と `小 / 中 / 大` の2列選択。技は未選択でもOK。前の問題で獲得した残ゲージに応じたグレーアウト表示。選択取り消し可能。
3. ホストからACKを受け取った選択だけ「準備完了」。問題表示400ms前に確定し、それ以降の入力は安全に無視。
4. 問題表示→回答→結果。回答速度・正誤は既存と同じ。技は同問に正解した場合だけ効果を出す。
5. 答え合わせ後に全員へ「ピピットが超速スパーク【中】発動！＋5ダメージ」等を表示。未発動は本人のみに表示。他人の宣言を解答前に明かさない。
6. エフェクト：小技0.5秒、中技0.8秒、大技最大1.2秒。過度な光点滅を避け、`prefers-reduced-motion`で静止版に切替。スマホの対戦時間を延ばさない。

## 苦手の固定保護
苦手ジャンルで不正解/時間切れの場合、受けるダメージから**固定2HPを一度だけ差し引く**（最低0）。以前の『防御1.4倍』や多段の%倍率は使わない。これは苦手ジャンルのストレスを少し下げる補助、メイン効果はゲージの増減。

## ネットワーク
- 既存ホストが `meter, pendingSkill, streak, firstStreak, statuses` を管理。クライアントは `gameId, round, skillId, tier, nonce` の選択意思だけ送る。
- `skillIntent → skillAck → answer → res`。回答後に一括解決し、`res.skillEvents` へ公開済みイベントを入れる。
- タイマーが切れた際の取り消し・再送・途中参加・再接続・重複パケットで二重消費しない。
- CPUも同じ正解発動ルール。COOP/アプリ間通信の遅延で公平性を損ねない。
