# コツンズ 早押しバトル

リンクで最大10人。近くの人とスマホをコツンしてキャラを生み、早押しクイズで戦うスマホ向けゲームの試作です（ISC322 ソフトウェア開発 最終課題）。

- 遊ぶ: https://ykcoder3.github.io/kotsunz/
- 1台だけでも「1人で試す（CPU 3人と対戦）」で遊べます。
- キャラ・レベル・戦績は、そのスマホのブラウザに保存されます。

## 通信のしくみ
全員が公開の MQTT 中継サーバーにつなぎ、部屋コードごとの宛先でメッセージをやりとりします。スマホ同士を直接つながないので、モバイル回線や学校の Wi-Fi でも通ります。ホストのスマホが問題を出し、答えの速さとダメージを計算します。中継サーバーは EMQX → HiveMQ → Eclipse Mosquitto の順に、つながるものを使います（どれも無料のテスト用サーバーで、APIキーは不要）。

## 使っているもの
- MQTT.js 5.16.1（MIT License）… 中継サーバーとの通信
- qrcode-generator 1.4.4（MIT License, Kazuhiko Arase）… 招待用QRコード
- キャラと国旗の絵、クイズの問題文は自作。音楽イントロの音はページ内で合成し、曲は作曲者の死後70年以上たったクラシックと古謡だけです。

## データについて
記録はブラウザの中だけに保存し、外には送りません。対戦中に部屋の人へ送るのはニックネーム・キャラ・答えだけです。公開サーバーを通るので、本名や個人情報はニックネームに入れないでください。
