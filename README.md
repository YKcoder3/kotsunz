# コツンズ 脳速クイズバトル

リンクで最大10人。近くの人とスマホをコツンしてキャラを生み、早押しクイズで戦うスマホ向けゲームの試作です（ISC322 ソフトウェア開発 最終課題）。

- 遊ぶ: https://ykcoder3.github.io/kotsunz/
- 1台だけでも「1人で試す（CPU 3人と対戦）」で遊べます。
- アカウント（ニックネームと4けたのあいことば）でログインします。アカウントとキャラ・レベル・戦績は、そのスマホのブラウザに保存されます（サーバーは使いません）。
- 別のスマホへは「引き継ぎコード」（暗号化して中継サーバーで一時的に受けわたし）か、バックアップファイルで移せます。
- ホーム画面に追加すると、アプリのように開けます（manifest.webmanifest とアイコン）。

## 通信のしくみ
全員が公開の MQTT 中継サーバーにつなぎ、部屋コードごとの宛先でメッセージをやりとりします。スマホ同士を直接つながないので、モバイル回線や学校の Wi-Fi でも通ります。ホストのスマホが問題を出し、答えの速さとダメージを計算します。中継サーバーは EMQX → HiveMQ → Eclipse Mosquitto の順に、つながるものを使います（どれも無料のテスト用サーバーで、APIキーは不要）。

## 使っているもの
- MQTT.js 5.16.1（MIT License）… 中継サーバーとの通信
- qrcode-generator 1.4.4（MIT License, Kazuhiko Arase）… 招待用QRコード
- キャラ・ロゴ・アイコン・国旗の絵、クイズの問題文は自作。音楽イントロの音はページ内で合成し、曲は作曲者の死後70年以上たったクラシックと古謡だけです。

## データについて
記録はブラウザの中だけに保存し、外には送りません。あいことばはそのまま保存せず、SHA-256で変換した値だけを保存します。引き継ぎのデータはAES-GCMで暗号化してから送ります。対戦中に部屋の人へ送るのはニックネーム・キャラ・答えだけです。公開サーバーを通るので、本名や個人情報はニックネームに入れないでください。

## キャラクター・ガチャ・ランク戦（v6）
- v6 で全員のデータ（アカウントもふくむ）を一度だけ初期化しました。前のバージョンのキャラ・バックアップは使えません。
- マスターは `data/characters_50.json`・`data/forms_150.json`・`data/game_config.json`。数値はすべて `game_config.json` にまとめています。
- はじめてのアカウントは「無料10連チケット1枚」と「覚醒石5個」。
- コツcoin：N人の試合なら1位Nコイン…最下位1コイン。ランク戦は2倍、コンピューター対戦はなし。ガチャは単発10・10連100。
- 進化：S1→S2は覚醒石2個、S2→S3は覚醒石3個とLv20以上。同じキャラが重なったら、重ねて経験値にできます。
- 覚醒石の入手：称号をとる・ランク戦のシーズン報酬（ゴールド以上に上がったとき）・購入（今後。いまは未実装）。
- シールド：正解したのに早押しで負けた人は、受けるダメージが半分。
- ランク戦：全ジャンル＋9グループで別々にdivision（ブロンズ〜レジェンド）。1位+30pt〜最下位−30pt。毎月新シーズン（ポイント半分）。
- 称号は153種類。プロフィールで1つつけて、ロビーやプロフィール共有で見せられます。
- 対戦の強さは全キャラ共通。違いは属性ごとの特技と相性（1.05倍）だけ。
- 記録はブラウザの中だけ（サーバーなし）なので、ランクは自分の記録で、全国ランキングではありません。お金での購入は実装していません。
- 画像は未制作のため、各キャラのワンポイントを描いたSVGで表示。正式な画像は `assets/characters/k001/stage-1.webp` に置き、`forms_150.json` の `assetStatus` を `ready` に。

## 500体と必殺技（v7・ブランチ v7-specials）
- キャラは500系統（K001〜K500）×3段階＝1500形態。K001〜K050 のIDと名前は v6 のまま。v6 の保存データは消さずに引きつぎ、変換する前のデータを端末の中に1回だけ控えます（`kotsunz-bak-v6-<uid>`）。
- マスター：アプリに埋めこむのは `data/kotsunz_master_500.json`（名前・属性・レア度・得意/苦手・技）と `data/special_config_v3.json`（必殺技の数値。これが唯一の正）。物語の文章は `data/kotsunz_lore_500.json` を開いたときだけ読みこみます。元のパックの JSON・CSV・仕様書は `data/v4/` と `docs/v4/` に置いています。作り直しは `tools/gen_master.py`。
- 必殺技：ジャンル発表のあと、問題が出る前に「⚔️攻撃・🛡守り・固有技」と「小25・中55・大90」をえらびます。その問題に正解したときだけ発動してゲージを使い、まちがえたら不発でゲージは使いません。ゲージは0〜100、はじめは10。だれが何を使ったかは答え合わせのあとに全員へ出し、ゲージは本人にしか送りません。
- 判定はすべてホストのスマホ（`skill` → `skack` → `res.skillEvents`）。クライアントが送るのは技の種類・段階・nonce だけで、ダメージやゲージの値は受けつけません。締め切りは問題が出る400ミリ秒前。
- 旧バージョンの「得意ジャンルでこうげき1.5倍」「苦手で防御1.4倍」「属性有利1.05倍」「属性ごとの常時特技」はなくしました。得意・苦手・属性はゲージの増減だけに効きます。例外として、苦手ジャンルでまちがえたときは受けるダメージを2だけ減らします（割合ではなく固定）。
- 進化：S1→S2 は「同じキャラのS1を3体（2体が素材）」か「覚醒石2個」のどちらか。S2→S3 は覚醒石3個とLv20（v6で決めた条件）。ロック・お気に入り・使用中のキャラは素材にしません。
- 絵：`assets/proto/kNNN/stage-N.svg` は SVG の**仮画像**です。正式なイラストは未制作で、`assets/characters/kNNN/stage-N.webp` を置くとビルド時に見つけて優先表示します（ないファイルは読みにいきません）。`art/premium_reference` の参考画は画風の見本なので、アプリには入れていません。
- コラボ：Disney・アニメ・ドラマなどの他社作品は、権利者の許可がないので入れていません。30枠のロックしたデータ（`data/v4/collab_slots_30_disabled.json`）と、状態を見るだけの管理画面（「このアプリについて」から）だけです。
- 有料のガチャ・購入は実装していません。
