# コツンズ 脳速クイズバトル

リンクで最大10人。近くの人とスマホをコツンしてキャラを生み、早押しクイズで戦うスマホ向けゲームの試作です（ISC322 ソフトウェア開発 最終課題）。

- 遊ぶ: https://ykcoder3.github.io/kotsunz/
- 1台だけでも「1人で試す（CPU 3人と対戦）」で遊べます。
- アカウント（ニックネームと4けたのあいことば）でログインします。アカウントとキャラ・レベル・戦績は、そのスマホのブラウザに保存されます（サーバーは使いません）。
- 別のスマホへは「引き継ぎコード」（暗号化して中継サーバーで一時的に受けわたし）か、バックアップファイルで移せます。
- ホーム画面に追加すると、アプリのように開けます（manifest.webmanifest とアイコン）。

## 通信のしくみ
全員が公開の MQTT 中継サーバーにつなぎ、部屋コードごとの宛先でメッセージをやりとりします。スマホ同士を直接つながないので、モバイル回線や学校の Wi-Fi でも通ります。ホストのスマホが問題を出し、答えの速さとダメージを計算します。中継サーバーは EMQX → HiveMQ → Eclipse Mosquitto の順に、つながるものを使います（どれも無料のテスト用サーバーで、APIキーは不要）。

## 使っているもの
- MQTT.js 5.16.1（MIT License）… 中継サーバーとの通信
- qrcode-generator 1.4.4（MIT License, Kazuhiko Arase）… 招待用QRコード
- キャラの絵は開発者が用意した新450パックの画像（権利の記録は確認中）。ロゴ・アイコン・国旗の絵、クイズの問題文は自作。音楽イントロの音はページ内で合成し、曲は作曲者の死後70年以上たったクラシックと古謡だけです。

## データについて
記録はブラウザの中だけに保存し、外には送りません。あいことばはそのまま保存せず、SHA-256で変換した値だけを保存します。引き継ぎのデータはAES-GCMで暗号化してから送ります。対戦中に部屋の人へ送るのはニックネーム・キャラ・答えだけです。公開サーバーを通るので、本名や個人情報はニックネームに入れないでください。

## 新450キャラ（v9・ブランチ v9-new450）
- キャラは NZ001〜NZ450 の450系列×3段階＝1350形態だけ。旧キャラ（K001〜K500）のマスター・名前・絵・仮画像・物語はすべて削除しました。
- マスター：`data/characters_450.json`・`data/forms_1350.json`・`data/special_skills_450.json`・`data/special_config_new450.json`（開発者が用意した「KOTSUNZ NEW450パックV3」）。アプリに埋めこむのは `tools/gen_master450.py` で作る `data/nz_master_450.json`・`data/nz_genre_map.json`。物語は `data/nz_lore_450.json` を開いたときだけ読みます。
- 絵：`assets/characters/NZxxx/stage-N.webp`。パックの3連絵（`assets/families/`）の元の画素だけを使い、背景を抜いて切り出し直しました（`tools/fixcrop2.py`）。描き直し・AIでの再生成はしていません。
- 旧データの初期化：はじめて開いたときに1回だけ、`kotsunz` で始まる旧データ（アカウント・キャラ・コイン・戦績・バックアップ）を消します。`localStorage.clear()` は使わず、ほかのサイトのデータは消しません。完了の目印は `kotsunz_catalog_epoch_new450_v2`。新しいデータには `epoch` をつけ、目印のない古いタブ・古いバックアップ・古いアプリからのオンライン参加は受けつけません。初期化のあと1回だけお知らせを出します。
- 必殺技（v4）：各キャラに固有技2つ（2つ目はS2で解放。スーパーレア・レジェンドはS1から）。ATTACKは1位正解のときだけ、DEFENDは宣言が受理されたら正誤に関係なく（ダメージ0でも消費）、RECOVERは正解なら順位に関係なく発動。回復は同じ問題のダメージと合わせてプラスならKOしない。あふれた回復は次の1問だけ小さなシールド。ミラー技は実際に防いだ分だけを、次に1位正解したとき少し返します。
- ゲージは発動したら0にもどります（パックは「コストだけ引く」ですが、作者の指定を優先）。固有の回復技がないキャラは RECOVER を押せません。
- 4択クイズ・早押し・問題・CPU（3段階）・オンライン対戦・部屋コード・ガチャ・育成・進化のルールは変えていません。
- 公開について：21枚の元シートの制作元・利用条件の記録がまだないため、`scripts/approve_release.py --check` は未完了です。`publishable` は false のままで、main（公開ページ）には出していません。状況は `docs/NEW450_RELEASE_STATUS.md`。

## 問題の追加とCPUの強さ（v8・ブランチ v8-questions）
- `KOTSUNZ_Combined_2101.json`（2,101問）から、既存の問題と重複しない1,996問を追加。重複105問は入れていない。ジャンルは52→82（既存はそのまま）。くわしくは `docs/QUESTIONS_V8.md`。
- 国旗を40→78種類に。写真・ロゴ・地図クイズ125問は素材と権利の確認前なので出さない（`data/photo_quiz_v8.json`・`data/media_license_ledger.json`）。
- CPU対戦の強さを3段階（よわい・ふつう・つよい）に。「ジャンル・問題数」の設定で選ぶ。
- 正解・解説・問題IDは、結果が決まってから配る（問題の配信には入れない）。
